# המתכונים של תפארת

**האפליקציה:** https://3368499-blip.github.io/matkonim/

205 מתכוני המשפחה (מהאתר "המתכונים של תפארת"), עם התמונות, תמונות המקור והסרטונים. כל מי שפותח את האפליקציה מקבל את כל המתכונים, ויכול להוסיף, לשנות ולמחוק אצלו.

אפשר גם לסרוק תיקיית תמונות, והאפליקציה מוצאת מה מהן מתכונים, מקלידה אותם (כתב יד, צילומי מסך, דפים מספר) וממיינת לקטגוריות.

- **בלי הגדרות:** הסריקה רצה בתוך הדפדפן, בחינם. טובה לצילומי מסך ולטקסט מודפס.
- **עם מפתח Gemini חינמי** (תפריט ← מנוע הסריקה): קריאה של כתב יד, מיון חכם, וחיפוש מתכונים באינטרנט עם קישור לאתר המקור.
- המתכונים נשמרים רק בדפדפן של המשתמש. שיתוף של מתכון, נושא או הכל: קישור (בלי שרת), טקסט או קובץ עם תמונות.
- אפשר להתקין בטלפון ("הוספה למסך הבית"), והיא עובדת גם בלי אינטרנט.
- כשבתמונה שנסרקה יש צילום של המנה, הוא נחתך ונהיה התמונה הראשית של המתכון (אפשר להחליף או להסיר).
- כל 29 הסרטונים שמורים באפליקציה עצמה.
